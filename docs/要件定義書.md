# 要件定義書

## タスク管理アプリ（トレロ風）

---

## 1. プロジェクト概要

カンバンボード形式の個人向けタスク管理アプリを作成する。  
タスクをカード形式で管理し、ドラッグ&ドロップでステータスを更新できる。  
タスクを達成したときに祝福の演出を表示してモチベーションを上げる。

---

## 2. 対象ユーザー

- **1人で**タスクを管理したい人

---

## 3. 機能要件（作るもの）

| 機能 | 内容 |
|------|------|
| タスク追加 | 各カラムにタスクカードを追加できる |
| タスク削除 | カードを削除できる |
| タスク移動 | ドラッグ&ドロップでカードを別カラムへ移動できる |
| データ保存 | ページを閉じてもデータが消えない（LocalStorage） |
| 達成演出 | Doneに移動したときに祝福のアニメーションを表示する |

---

## 4. スコープ外（作らないもの）

- 複数人での共有・リアルタイム同期機能
- ログイン・パスワード機能
- タスクの期限設定機能

---

## 5. 画面設計（ワイヤーフレーム）

```
┌────────────────────────────────────────────────┐
│              タスク管理アプリ                    │
├────────────┬───────────────┬────────────────────┤
│    Todo    │  In Progress  │       Done         │
│ ┌────────┐ │  ┌────────┐   │  ┌────────┐        │
│ │タスク名 │ │  │タスク名│   │  │タスク名│🎉      │
│ │  [削除] │ │  │ [削除] │   │  │ [削除] │        │
│ └────────┘ │  └────────┘   │  └────────┘        │
│            │               │                    │
│ [+ 追加]   │               │                    │
└────────────┴───────────────┴────────────────────┘
                                    ↑
                             Doneに移動したら
                             🎉が表示される
```
